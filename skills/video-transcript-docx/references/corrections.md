# 怎么找出并修掉 ASR 的错误

**这一步不能自动跳过。** ASR 的中文主体通常没问题，错的是专有名词——而专有名词恰好
是听课笔记里最重要的部分（工具名、书名人名、术语）。热词只能救一小部分，剩下的必须
靠**通读一遍 + 写定向规则**。

## 流程

1. **先读一遍全文**，把明显不对的地方挑出来。工具名、人名、书名、英文术语是重灾区。
2. **逐条抓上下文**（不要只看词本身），判断本来应该是什么。
3. 写成 `rules.json`，跑 `make_docx.py`，**看它报的每条规则命中次数**。
4. 命中 0 次的规则 → 要么已经被热词修好了，要么规则写错了。查一下。
5. 再读一遍输出，找**新暴露出来的**错误（第一遍可能被前面的错掩盖了）。
6. 重复到没有新发现。

## 写规则的技术要点

### 绝对不要在中文旁边用 `\b`

Python 的 `re` 里中文字符算 word character，所以 `\bobsidian\b` 在"叫obsidian啊"
这种位置**根本不匹配**——"叫"和"o"之间没有词边界。

要用环视：

```python
L = r"(?<![A-Za-z])"
R = r"(?![A-Za-z])"
(L + r"obsidian" + R, "Obsidian")
```

### 同一个词的错法会跨版本变化

实测"AI"这一个词被识别成 `AR`、`ar`、`IR` **三种**写法。更麻烦的是：换模型重跑之后，
错法会变——上一版是 `针位`，这一版变成 `真位`。

所以：

- 大小写要覆盖：`(?i:ar)`、`(?i:ir)`，别只写一种
- **每轮重跑后都要重新扫一遍**，不能照搬上一轮的规则表

### 同一个词可能有两种含义

实测 `notebook` 既指 **Jupyter Notebook**，又指 **NotebookLM**，同一段视频里都有。
必须先按上下文写具体规则，最后才用兜底规则收剩下的。顺序错了就会全变成同一个词。

```python
(r"还有这个notebook", "还有这个 Jupyter Notebook"),
(r"notebook\s*LM", "NotebookLM"),
(L + r"notebook" + R, "NotebookLM"),   # 兜底放最后
```

### 顺序敏感：长的、具体的放前面

`quick salort` 要在 `salort` 之前；`primiy` 要在 `prim` 之前。

## 判断哪些该改、哪些别碰

**该改**：工具名、产品名、书名人名、学科术语、明显同音字（记比一 → 记笔记、
很大不头 → 很大部头）。

**别碰**：

- 口语里的停顿、重复、口头禅——那是**原话**，删掉是篡改。（要清爽版本的另出一份
  "精简版"，让用户自己挑，别只给一份。）
- 你**判断不出原话**的地方。宁可留着，在交付时**明确列出来**告诉用户，也不要猜。
  实测有"cream agreem""还没有进贤屋"这类完全听不出来的片段，编一个只会误导。

## 交付时要说清楚

一定要讲明**这是机器转写、没有逐句人工校对**，并列出：

- 你修了哪些（给个清单，让用户能复核）
- 哪些你判断不出、原样留着
- 已知的局限（比如热词反而插错的地方）
