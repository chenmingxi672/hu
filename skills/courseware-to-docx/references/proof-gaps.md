# 找出并补全"被略去的证明"

## 为什么值得做

课件和教材里，讲师经常用一句话把一整个证明带过去：

> 同理可证 / 由（另页）例可知 / 显然 / 用同样的方法可得

这些地方对**当堂听讲的人**是够的——他刚看过那个构造。但整理成稿之后，读者手上**只有这份稿子**，
那句话就成了死路：他没法"同理"，因为他不知道那个"理"是什么。

判断标准就一条：**只靠这份稿子，读者能不能把这个缺口自己补出来？**
补不出来的，就是真缺口。

## 先扫一遍

```
python find_gaps.py notes.md
```

它按可疑程度排出候选并附上下文。**注意它不判断**——有些"同理"是真的重复同一个构造
（那就不必展开），有些背后藏着一整个没写的证明。逐条回原文看。

## 候选的分类与处理

| 情形 | 处理 |
|---|---|
| **引用别处**（"由另页例可知"） | 那个例子本身必须补出来——读者多半没有"另页" |
| **对称论证**（"同理可证"） | **先确认方向真的对称再照抄**，见下 |
| **只给结论、没给证明** | 从定义出发完整写 |
| **"显然/易见"** | 可能是真显然（一句话点破即可），也可能跳了一大步。按读者视角判断 |
| **前文已证** | 回查前文，确实证过就保留原话 |

## 两个容易出错的点

### 一、"同理"往往并不真的同理

**实测踩过**：Dedekind 基本定理的两个情形。情形 1 用的是「$A'$ 向下封闭 + $B$ 向上封闭」，
情形 2 必须换成「$B'$ 向上封闭 + $A$ 向下封闭」——**方向要对调**。
直接照抄情形 1 并把不等号反过来，会写出一段看着像、其实不成立的证明。

**做法**：不要"镜像复制"，而是**重新推一遍**，确认每一步的依据在新情形下仍然存在。

### 二、顺手能发现原文的笔误

实测在阿基米德性质的证明里发现原文写的是

> $(n+1)a < \alpha$

但从 $(n+1)a \in A$ 与 $\alpha = \sup A$ 只能推出 $(n+1)a \leq \alpha$，**等号可能取到**。

补证明时要顺手核对原式本身。**发现笔误就改，并在文中加一条「订正说明」**——
读者手上可能还有原课件，不作说明他会以为你抄错了。

## 补的时候，不要编

**判断不出原话的地方，宁可留着，并在交付时明确列出来。**

实测遇到过的：一句听不出原意的口语、一个指向不存在的页码的引用。猜一个填上去，
比留个空更糟——读者会以为那是原文。

## 写的时候

- 用**和你替换掉的那句话相同的记号体系**。原文用 $A|B$ 表示分割，你就别换成 $(A,B)$。
- 引用前文的结论时**把编号带上**（"由引理 2"、"由例 3"），方便读者回查。
- 补的部分最好让读者能一眼看出接在哪里——从"证"接着写，别另起一套。

## 输出两份：原文版与补充版

用户要的往往是**对照**——"原文长什么样"和"补全后长什么样"。所以**两份都出**：

- **原文版**：只含课件本身的内容，你补的一个字都不许进去。
- **补充证明版**：原文 + 你的补充。

**做法是一份源文件 + 标记**，不是写两份：

```markdown
<!--SUPP-->
...你补的内容...
<!--/SUPP-->
```

然后 `split_supp.py` 拆成两个文件。只写一份的好处是**两个版本不可能走样**：
改共享正文里的错别字，两边同时生效；而且原文版是**可证明干净**的——只要标记写全了，
它里面就不可能有你的东西。写两份的话，迟早会出现"改了补充版忘了改原文版"。

**唯一的例外是「订正说明」**：原文笔误的更正说明**两版都留**。理由——读者手上
可能同时有课件和你的整理稿，不作说明他会以为你抄错了。交付时必须点出这一点，
否则用户看到原文版里有"订正"两个字会以为原文版没干净。

拆完回读一遍原文版，扫一下有没有补充漏进去。

## 补充要融入正文，不要留工作痕迹

标记是给脚本看的。**成品里不该出现"补充：xxx""课件这里没证，我补上"这类话**——
那是在读者的阅读路线上每隔几段插一块路障。

写的时候：

- 证明**接着原文的"证："往下写**，不要另起带抬头的段落。
- 删掉一切自述整理过程的句子（"课件没有给证明""此处补全""补充说明"）。
- 说明某条结论的来历时**用数学语言**（"由前面例⑦""由保号性推论二"），
  而不是"课件在第 N 页说过"。
- 跨节引用、教材页码这类必要出处，写成不打断句子的括注。

**反面例子**：

> **补充：为什么均值不等式重要。** 课件从例④起反复用它，却从头到尾没证。下面补上。

**正面写法**：

> 这里反复用到的**均值不等式**是：设 $x_1,\dots,x_n>0$，则 $\sqrt[n]{x_1\cdots x_n} \leq \frac{x_1+\cdots+x_n}{n}$。
> 用反向归纳法证明：第一步（$n=2$）……

自检办法：把补充版通读一遍，**如果某一段读起来像"我在向你解释我做了什么"，
那段就写错了**。整理稿的读者不关心整理的过程。

## 遇到"另页例"：要指明是第几页

课件里常见"由（另页）例可知""见前面某例"，而**读者手上没有"另页"**。
最差的做法是原样照抄这句话——等于把一个缺口又往后推了一格。

**整理阶段就记页码。** 逐页读图时顺手记下"第 N 页 = 哪个例子/定理/引理"，
形成一张页号索引。这张索引是后面所有跨页引用的地基，**没有它就只能靠猜**。

补的时候：

- **能定位的**，直接写出来："课件第 24 页的例 3 给出的正是这条引理，其中 $\delta$ 取……"
- **定位不到的，明说定位不到**，不要含糊，更不要随手指一页。

若引用指向的是**教材页码**（"P25 例 2.1.3""P37 习题 1(1)"），而教材 PDF 也在手边，
直接翻那页核对，**优先用教材原有的证法**——记号、思路都对得上，读者体验最好。

## 如果手上还有教材 PDF

课件里"P25 例 2.1.3""P37 习题"这类页码指的是**教材**，不是课件。若教材 PDF 也在，
补之前先翻一下对应页：**优先用教材原有的证法**，而不是你自己另写一套。
记号、思路都对得上，读者体验最好。
